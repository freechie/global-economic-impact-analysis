# Data profiles

The notebook reads one complete profile through `AnalysisBundle`. A profile directory contains `profile.json` and eight CSV files. The manifest declares the schema version, the profile ID, the classification of each table, its source or generator metadata, and its SHA-256 hash.

## Public classifications

The tracked `public-demo` profile uses these classifications:

| Table | Classification | Meaning |
| --- | --- | --- |
| `gdp_annual` | Open | World Bank Open Data, GDP (current US$), CC BY 4.0. The public file is normalized and records its changes and year coverage in `profile.json`. |
| Other seven canonical tables | Synthetic | Deterministic fictional values generated by `scripts/generate_public_profile.py`. |

Synthetic values are fictional and are not observed measurements.

## Canonical table contract

The frozen `DATASET_SPECS` registry in `src/data_loader.py` defines these ordered columns:

| Table | Ordered columns |
| --- | --- |
| `gdp_annual` | `country_name`, `country_code`, `year`, `nominal_gdp_usd`, `is_aggregate` |
| `arms_by_category_annual` | `direction`, `category`, `year`, `activity_value` |
| `arms_by_entity_annual` | `direction`, `source_entity`, `country_name`, `country_code`, `mapping_status`, `exclusion_reason`, `year`, `activity_value` |
| `aircraft_orders_monthly` | `date`, `manufacturer`, `net_orders` |
| `defense_budget_annual` | `request_year`, `category`, `nominal_usd_bn` |
| `cyber_fund_flows_monthly` | `date`, `fund`, `net_flow_usd_m` |
| `airline_cds_monthly` | `date`, `region`, `spread_bps` |
| `homebuilder_confidence_annual` | `year`, `index_value` |

`country_name`, `country_code`, and `exclusion_reason` are nullable only in `arms_by_entity_annual`. An excluded entity records a reason. A mapped entity records its geographic scenario.

## Regenerate the public profile

Run:

```bash
python3 scripts/generate_public_profile.py
```

The first repository migration normalized the confirmed open GDP file already present in the repository. A fresh public clone regenerates from the tracked canonical GDP table and never needs a legacy local file. To refresh GDP from a new World Bank download, keep the source outside restricted local profiles and run:

```bash
python3 scripts/generate_public_profile.py --gdp-source data/open/world-bank/gdp.csv
```

The generator uses closed formulas, stable sorting, fixed rounding, and stable JSON formatting. Running it twice produces byte-identical profile artifacts.
